# Project Decision Log

## 1: Вибір архітектури проекта
Дата: 8.10
Статус: Прийнято
Контекст: Потрібно розробити мультиплатформний додаток тз каталогом фільмів, розрахований на безпечну роботу із зовнішніми API
Рішення: ASP.NET Core Web API + .NET MAUI
Причина:
  * Ключ TMDB API та секретні ключі JWT зберігаються на бекенді і не потрапляють на клієнт
  * У майбутньому до API можна буде підключити мобільний клієнт Android без зміни бізнес-логіки

## 2: Налаштування CI/CD інфраструктури
Дата: 23.10 
Статус: Прийнято 
Контекст: Потрібно налаштувати автоматичне тестування при кожному Pull Request, але наявність MAUI-клієнта в єдиному Solution ускладнюватиме збірку через відсутність мобільних SDK на серверах.
Рішення: Використати GitHub Actions, вказавши явний шлях до `.csproj` файлу тестів замість `.sln`.
Причина: 
  * Дозволяє швидко та стабільно запускати тести бекенду.
  * Ігноруються мобільні залежності MAUI, оскільки для швидкої перевірки бізнес-логіки достатньо ізольованих API-тестів. Тестування клієнтського інтерфейсу, за потреби, буде налаштовано в окремому CI-пайплайні зі специфічним середовищем.
